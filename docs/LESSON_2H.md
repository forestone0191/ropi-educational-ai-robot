# 로피 2시간 수업 설계 (선생님용)

초등학생 대상, 2시간, 로봇 여러 대. 실제로 로봇 5대를 세팅하면서 겪은 문제들을 반영했습니다.

---

## 제일 중요한 원칙

> **환경 세팅을 가르치지 마세요. 미리 다 해놓고 "접속"만 가르치세요.**

2시간에 WSL 설치를 넣으면 **그것만으로 2시간이 갑니다.**
관리자 권한이 막힌 노트북이 한 대라도 나오면 그 학생은 아무것도 못 하고 끝납니다.

환경 문제는 예측이 안 됩니다. 실제로 겪은 것들만 나열하면 이렇습니다.

- 갓 부팅한 파이가 자동 업데이트를 돌려 설치가 막힘
- PCA9685가 배선은 멀쩡한데 스캔에 안 잡힘
- 서보 커넥터가 빠져 있었음 (5대 중 2대)
- 와이파이 대역이 바뀌어 로봇을 못 찾음
- 서보 1개 고장

**[PowerShell 매뉴얼](MANUAL_WINDOWS_POWERSHELL.md)을 쓰세요.** 설치 단계가 통째로 없어집니다.
아이들이 치는 건 사실상 **명령어 두 줄**입니다.

**말로 조종하는 수업을 하실 거면** [음성 AI 매뉴얼](MANUAL_VOICE_POWERSHELL.md)을 보세요.
다만 준비가 훨씬 많습니다 — 파이썬 설치, 마이크 권한, 로봇 서버 켜기, API 키.
**2시간에 키보드 조종과 음성을 다 넣으면 둘 다 못 합니다.** 하나만 고르세요.

## 깃허브 계정은 만들게 하지 마세요

**필요 없습니다.** 공개 저장소는 계정 없이 `git clone` 됩니다.
PowerShell 조종 방식은 git 조차 쓰지 않습니다 — 코드가 이미 로봇 안에 있으니까요.

그리고 만들게 하면 안 되는 이유가 있습니다.

| 항목 | 기준 |
|---|---|
| GitHub 이용약관 | 만 13세 이상 |
| 한국 법 (개인정보보호법·정보통신망법) | **만 14세 미만은 법정대리인 동의 필요** |

초등학생은 대부분 만 14세 미만이라 **보호자 동의를 확인받아야 합니다.**
20명 학부모 동의를 캠프 전에 받는 건 현실적으로 무리입니다.

**코드를 노트북에 받아야 한다면:**

- GitHub 페이지에서 `Code` → `Download ZIP` (git 도, 계정도 필요 없음)
- 또는 **선생님이 미리 노트북에 넣어두기** (수업 시간도 벌립니다)

**학생 작업물을 제출받고 싶으면** USB·공유폴더·이메일을 쓰세요.
공용 계정을 학생들과 돌려쓰는 것은 **GitHub 약관 위반**(1인 1계정)이라 하지 마세요.

## 0:00–0:10 — 시연

**설명하지 말고 먼저 보여주세요.** 선생님이 조종기로 로봇을 운전하고, 공격하고, 손 흔들게 합니다.

"이거 너희가 직접 조종할 거야"로 시작하면 그다음 20분의 지루한 명령어 입력을 견딥니다.

## 0:10–0:20 — 접속

**칠판에 이 두 줄만 크게 써두세요.**

```
ssh stone0191@192.168.0.__
```

```
cd ~/ropi_robot && source venv/bin/activate && python3 raspberry_pi/ropi_teleop.py
```

### IP를 쓰세요, 이름을 쓰지 마세요

윈도우는 `.local` 이름 찾기가 종종 실패합니다. **로봇 몸통에 IP를 큰 스티커로 붙여두세요.**
아이가 자기 로봇 번호만 보고 치면 됩니다.

### 미리 말해줄 것 두 가지

이 둘만 알려주면 질문의 절반이 사라집니다.

1. **"비밀번호는 쳐도 화면에 안 보여. 고장 아니야. 그냥 치고 엔터."**
2. **"`yes`는 세 글자 다 쳐야 해. `y` 하나로는 안 돼."**

### 자주 나오는 질문 대응표

| 아이가 하는 말 | 원인 | 대응 |
|---|---|---|
| "이름을 못 찾겠다고 나와요" | 와이파이가 다르다 | 노트북 와이파이 확인 |
| "연결을 거부당했어요" | 로봇이 아직 부팅 중 | 1분 기다리기 |
| "비밀번호가 안 쳐져요" | 원래 안 보인다 | 그냥 치고 엔터 |
| "로봇이 안 움직여요" | `source venv/bin/activate` 빼먹음 | 두 번째 줄부터 다시 |
| "방향키가 안 먹어요" | 창이 선택 안 됨 | 창을 마우스로 클릭 |

## 0:20–0:40 — 운전

조종 키는 [매뉴얼](MANUAL_WINDOWS_POWERSHELL.md)에 표로 있습니다. 처음엔 이 다섯 개만 알려주세요.

| 키 | 동작 |
|---|---|
| **↑ ↓ ← →** | 움직이기 |
| **스페이스** | 멈추기 |
| **F** | 공격 |
| **H** | 손 흔들기 |
| **X** | 끝내기 |

나머지는 필요할 때 `?`를 눌러 보면 됩니다.

### 안전 규칙 3개

1. **책상 끝에서 하지 마세요.** 떨어집니다.
2. **팔 동작은 로봇을 들고 시험하세요.** 세게 휘둘러집니다.
3. **모터가 "웅—" 소리만 내고 안 움직이면 바로 스페이스.** 그대로 두면 뜨거워집니다.

## 0:50–1:20 — 내 로봇 길들이기 (핵심)

여기서 가르칠 개념은 하나입니다.

> ### "이 모터는 자기가 어디를 보고 있는지 몰라."

일반 서보는 "90도로 가"라고 하면 갑니다.
그런데 이 로봇의 모터는 **"어느 쪽으로 얼마나 빠르게 돌아라"만 알아듣습니다.**
위치 감각이 없습니다.

그래서 이런 일이 생깁니다. **아이들이 실제로 겪을 일이라 설명이 잘 먹힙니다.**

### ① 로봇마다 바퀴 방향이 다르다

W를 눌렀을 때:

| 증상 | 누를 키 |
|---|---|
| 제자리에서 **왼쪽으로** 빙글 | **1** |
| 제자리에서 **오른쪽으로** 빙글 | **2** |
| **뒤로** 간다 | **R** |

**제자리에서 도는 건 바퀴 하나가 거꾸로 돌고 있다는 뜻입니다.**
아이들에게 "왜 제자리에서 돌까?"를 먼저 물어보면 스스로 알아냅니다.

### ② 똑바로 안 간다

모터마다 실제 회전 속도가 미묘하게 다릅니다. 느린 쪽 바퀴를 빠르게 해줍니다.

| 키 | 동작 |
|---|---|
| **.** / **,** | 왼쪽 바퀴 빠르게 / 느리게 |
| **'** / **;** | 오른쪽 바퀴 빠르게 / 느리게 |

### ③ 고쳤으면 반드시 저장

```
P
```

**`P`를 안 누르면 다음에 처음부터 다시 해야 합니다.**

### 이 수업의 메시지

**"내 로봇은 내가 맞춰야 한다."**

10대가 다 조금씩 다르다는 걸 아이들이 직접 발견합니다.
같은 부품으로 만들었는데 왜 다른지, 그래서 왜 사람이 맞춰줘야 하는지가 이 수업의 내용입니다.

여기서 다시 돌아가서 맞춥니다.

## 미리 알아야 할 위험 두 가지

### 1. 배터리

보조배터리 스마트 회로를 우회한 구조라 셀 전압(3.0~4.2V)이 그대로 갑니다.
MG90은 4.8~6V 규격입니다.

**CR 서보는 전압이 떨어지면 회전 속도가 같이 떨어집니다.**
즉 배터리가 닳으면 **아침에 맞춘 보정값이 오후엔 안 맞습니다.**
2시간 수업 중에 로봇이 점점 삐뚤어질 수 있습니다.

**대응:** 여분 배터리를 준비하고, 아이들에게 미리 말해두세요.
"배터리가 약해지면 다시 맞춰야 해" — 그러면 문제가 오히려 학습 소재가 됩니다.

장기적으로는 **UBEC(5V/3A 강압 모듈)**을 넣는 게 맞습니다.

### 2. 와이파이

**강의실 와이파이가 세팅할 때 쓴 것과 같은지 미리 확인하세요.**
다르면 로봇을 전부 다시 설정해야 하고, 그건 2시간 안에 못 합니다.

다르다면 **전날 밤에 로봇마다 와이파이를 두 개씩 저장해두세요.**

```bash
ssh stone0191@ropi01.local 'sudo raspi-config nonint do_wifi_ssid_passphrase "강의실와이파이" "비번"'
```

기존 설정은 지워지지 않습니다. **둘 다 저장되어 어느 망에 가도 붙습니다.**

## 로봇 관리 명령 모음 (선생님용)

### 로봇 찾기 (맥)

```bash
for i in $(seq 1 254); do ping -c 1 -W 250 192.168.0.$i >/dev/null 2>&1 & done; wait
arp -a -n | grep -i 'b8:27:eb'
```

### 새 보드 세팅 (맥, 한 줄)

```bash
bash deploy_ropi.sh <IP> ropi06
```

### 팔 채널이 다를 때

로봇마다 배선이 다를 수 있습니다. 4호기는 팔이 CH8~11에 꽂혀 있었습니다.

```bash
# 지금 설정 보기
ssh stone0191@ropi04.local 'cd ~/ropi_robot && ./venv/bin/python3 raspberry_pi/ropi_motion.py channels'

# 바꾸기 (왼어깨 오른어깨 왼손 오른손)
ssh stone0191@ropi04.local 'cd ~/ropi_robot && ./venv/bin/python3 raspberry_pi/ropi_motion.py channels 8 9 10 11'
```

### 어느 채널에 무엇이 붙었는지 찾기

```bash
ssh -t stone0191@ropi04.local 'cd ~/ropi_robot && source venv/bin/activate && python3 raspberry_pi/ropi_scan.py 0 15'
```

### 모터가 안 멈출 때

```bash
ssh stone0191@ropi01.local 'cd ~/ropi_robot && ./venv/bin/python3 raspberry_pi/ropi_motion.py stop'
```
