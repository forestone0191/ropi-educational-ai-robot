# 로피(ROPI) 조종 매뉴얼 — 윈도우

로봇을 키보드로 움직이는 방법입니다. 순서대로 따라 하세요.

**1단계부터 4단계까지는 처음 한 번만 하면 됩니다.**
두 번째부터는 5단계로 바로 가면 됩니다.

> **로봇을 움직이기만 할 거라면 설치가 필요 없는 방법이 있습니다.**
> [MANUAL_WINDOWS_POWERSHELL.md](MANUAL_WINDOWS_POWERSHELL.md) 를 보세요. 훨씬 짧습니다.
> 이 문서(WSL)는 **코드를 직접 고쳐서 로봇에 보내거나, 음성 AI를 노트북에서 돌릴 때** 필요합니다.

---

## 준비물

- 윈도우 10 또는 11 노트북
- 로피 로봇 (전원이 켜져 있어야 합니다)
- **노트북과 로봇이 같은 와이파이에 연결되어 있어야 합니다** ← 제일 중요

선생님께 받아 적어 두세요.

| 항목 | 적는 곳 |
|---|---|
| 와이파이 이름 | |
| 와이파이 비밀번호 | |
| 내 로봇 이름 | `ropi____` |
| 로봇 비밀번호 | |

## 1단계 — WSL 설치 (처음 한 번만)

WSL은 윈도우 안에서 리눅스를 쓸 수 있게 해주는 프로그램입니다.

**① 시작 버튼을 누르고 `powershell` 이라고 칩니다.**

**② `Windows PowerShell` 위에서 마우스 오른쪽 버튼 → `관리자 권한으로 실행`**

> 꼭 **관리자 권한으로** 실행해야 합니다. 그냥 열면 설치가 안 됩니다.

**③ 파란 창이 뜨면 아래를 복사해서 붙여넣고 엔터**

```powershell
wsl --install
```

> 붙여넣기는 마우스 **오른쪽 버튼**을 누르면 됩니다. `Ctrl+V`가 안 될 수도 있어요.

**④ 설치가 끝나면 컴퓨터를 다시 시작합니다.**

```powershell
Restart-Computer
```

다시 켜지면 검은 창이 저절로 열리면서 설치가 이어집니다. **기다리세요.** 5분쯤 걸립니다.

---

## 2단계 — 우분투 첫 설정 (처음 한 번만)

검은 창에 이렇게 나옵니다.

```
Enter new UNIX username:
```

**① 이름을 영어 소문자로 칩니다.** (예: `minsu`) 그리고 엔터.

**② 비밀번호를 만듭니다.**

```
New password:
```

여기서 놀라지 마세요. **비밀번호를 쳐도 화면에 아무것도 안 보입니다.** 고장이 아닙니다. 원래 그렇습니다. 그냥 치고 엔터를 누르세요.

**③ 같은 비밀번호를 한 번 더 칩니다.**

```
Retype new password:
```

**이 비밀번호를 꼭 기억하세요.** 나중에 계속 씁니다.

끝나면 이런 글자가 나옵니다. 성공입니다.

```
minsu@DESKTOP-ABC123:~$
```

## 5단계 — 로봇에 접속하기

**여기서부터가 매번 하는 부분입니다.**

먼저 확인하세요.

- [ ] 로봇 전원이 켜져 있나요?
- [ ] 노트북이 로봇과 **같은 와이파이**에 연결되어 있나요?

검은 창(우분투)을 열고 아래를 칩니다. **`ropi01` 자리에 내 로봇 이름을 넣으세요.**

```bash
ssh stone0191@ropi01.local
```

**처음 접속할 때만** 이런 질문이 나옵니다.

```
Are you sure you want to continue connecting (yes/no)?
```

`yes` 라고 치고 엔터. (`y` 하나만 치면 안 됩니다. `yes` 세 글자를 다 쳐야 합니다.)

그다음 로봇 비밀번호를 칩니다. **역시 화면에는 안 보입니다.**

이렇게 바뀌면 성공입니다. 이제 여러분의 키보드가 로봇에 연결되었습니다.

```
stone0191@ropi01:~$
```

> **이름으로 안 되면 숫자 주소를 쓰세요.** 선생님께 로봇의 IP 주소를 물어보고
> `ssh stone0191@192.168.0.64` 처럼 치면 됩니다.

## 6단계 — 조종하기

접속된 상태에서 아래를 **한 줄씩** 칩니다.

```bash
cd ~/ropi_robot
```

```bash
source venv/bin/activate
```

```bash
python3 raspberry_pi/ropi_teleop.py
```

> **가운데 줄을 빼먹으면 안 됩니다.** `source venv/bin/activate` 를 안 하면
> 로봇이 움직이지 않습니다.

조종 키 목록이 화면에 나오면 준비 끝입니다. **이제 키보드를 누르면 로봇이 움직입니다.**

## 조종 키

### 움직이기

| 키 | 동작 |
|---|---|
| **↑** 또는 **W** | 앞으로 |
| **↓** 또는 **S** | 뒤로 |
| **←** 또는 **A** | 왼쪽으로 돌기 |
| **→** 또는 **D** | 오른쪽으로 돌기 |
| **Q** | 제자리에서 왼쪽으로 빙글 |
| **E** | 제자리에서 오른쪽으로 빙글 |
| **스페이스** | 멈추기 |

**키를 누르고 있는 동안만 움직입니다.** 손을 떼면 멈춥니다. 로봇이 혼자 굴러가지 않게 하려고 그렇게 만들었습니다.

### 빠르기

| 키 | 동작 |
|---|---|
| **+** | 빠르게 |
| **−** | 느리게 |

### 공격

| 키 | 동작 |
|---|---|
| **F** | 양팔 공격 |
| **J** | 왼팔 |
| **K** | 오른팔 |
| **G** | 콤보 (왼팔 → 오른팔 → 양팔) |

### 인사

| 키 | 동작 |
|---|---|
| **H** | 양손 흔들기 |
| **U** | 왼손 |
| **I** | 오른손 |

### 끝내기

| 키 | 동작 |
|---|---|
| **X** | 조종 끝내기 |
| **?** | 키 목록 다시 보기 |

## 내 로봇에 맞게 고치기

로봇마다 모터가 조금씩 달라서, 처음에는 이상하게 움직일 수 있습니다. 아래 키로 고칠 수 있습니다.

### 방향이 이상할 때

**W를 눌렀는데 이렇게 되면:**

| 이런 증상 | 누를 키 |
|---|---|
| 제자리에서 **왼쪽으로** 빙글 돈다 | **1** |
| 제자리에서 **오른쪽으로** 빙글 돈다 | **2** |
| **뒤로** 간다 | **R** |
| 앞으로 잘 간다 | 고칠 필요 없음 |

**F를 눌렀는데 팔이 뒤로 가면** → **T**
**H를 눌렀는데 손이 이상하게 움직이면** → **Y**

### 똑바로 안 갈 때

앞으로 가는데 한쪽으로 휘어지면, 느린 쪽 바퀴를 빠르게 해줍니다.

| 키 | 동작 |
|---|---|
| **.** | 왼쪽 바퀴 빠르게 |
| **,** | 왼쪽 바퀴 느리게 |
| **'** | 오른쪽 바퀴 빠르게 |
| **;** | 오른쪽 바퀴 느리게 |

### 다 고쳤으면 저장

```
P
```

**P를 눌러야 저장됩니다.** 저장하지 않으면 로봇을 껐다 켰을 때 처음으로 돌아갑니다.

## 안 될 때

### "이런 이름을 못 찾겠다"고 나와요

```
ssh: Could not resolve hostname ropi01.local
```

**노트북과 로봇이 다른 와이파이에 있는 겁니다.** 노트북 와이파이를 확인하세요.
그래도 안 되면 이름 대신 숫자 주소를 쓰세요. (`ssh stone0191@192.168.0.64`)

### "연결을 거부당했어요"

```
Connection refused
```

**로봇이 아직 켜지는 중입니다.** 1분 기다렸다가 다시 해보세요.

### 비밀번호가 안 쳐져요

**원래 화면에 안 보입니다.** 고장이 아닙니다. 그냥 치고 엔터를 누르세요.

### 로봇이 안 움직여요

```
ModuleNotFoundError: No module named 'adafruit_servokit'
```

**`source venv/bin/activate` 를 빼먹은 겁니다.** 6단계를 처음부터 다시 하세요.

### 바퀴 하나가 아예 안 돌아요

**선을 확인하세요.** 로봇을 옮기다 보면 커넥터가 빠지는 일이 자주 있습니다.
빠진 게 없으면 선생님을 부르세요.

### 로봇이 멈추지 않아요

**스페이스**를 누르세요. 그래도 안 되면 **`Ctrl` + `C`** 를 누르세요.
그것도 안 되면 **로봇 전원 스위치를 내리세요.**

## 안전 규칙

1. **팔 동작을 시험할 때는 로봇을 손으로 들고 하세요.** 팔이 세게 휘둘러집니다.
2. **책상 끝에서 주행 시험을 하지 마세요.** 떨어집니다.
3. **모터가 "웅—" 소리를 내면서 안 움직이면 바로 스페이스를 누르세요.** 그대로 두면 모터가 뜨거워집니다.
4. 다 하고 나면 **X**로 끝내고 **전원 스위치를 내리세요.**

## 선생님께

**주행만 시킬 거라면 WSL 없이도 됩니다.** 윈도우 10·11에는 SSH가 이미 들어 있어서
PowerShell에서 바로 `ssh stone0191@ropi01.local` 하면 접속됩니다.
WSL 설치는 관리자 권한과 재부팅이 필요해서, 학교 노트북에서는 막혀 있을 수 있습니다.

WSL이 필요한 경우는 이렇습니다.

- 학생들이 코드를 직접 고쳐서 로봇에 보내게 할 때 (`git`, `scp` 사용)
- 음성 AI 클라이언트를 노트북에서 돌릴 때 (파이썬 환경 필요)

**미리 준비해 두시면 좋은 것**

- 로봇마다 호스트이름을 다르게 (`ropi01` ~ `ropi10`). 안 그러면 `.local` 접속이 엉뚱한 로봇으로 갑니다.
- 와이파이 이름·비밀번호를 크게 적어 칠판에 붙여두기
- 로봇 IP 목록을 예비로 준비 (`.local`이 안 될 때를 대비)
- 수업 전에 8개 커넥터가 다 꽂혔는지 확인 (`ropi_scan.py`)
