# 로피(ROPI) 조종 매뉴얼 — 윈도우 (PowerShell)

**설치할 게 없습니다.** 윈도우에 이미 들어 있는 프로그램만 씁니다.

WSL을 쓰는 방법은 [MANUAL_WINDOWS.md](MANUAL_WINDOWS.md) 를 보세요.
로봇을 움직이기만 할 거라면 이 문서로 충분합니다.

---

## 준비물

- 윈도우 10 또는 11 노트북
- 로피 로봇 (전원이 켜져 있어야 합니다)
- **노트북과 로봇이 같은 와이파이에 연결되어 있어야 합니다** ← 제일 중요

선생님께 받아 적어 두세요.

| 항목 | 적는 곳 |
|---|---|
| 와이파이 이름 | |
| 와이파이 비밀번호 | |
| 내 로봇 이름 | `ropi____` |
| 내 로봇 숫자 주소 | `192.168.____.____` |
| 로봇 비밀번호 | |

> **숫자 주소를 꼭 적어두세요.** 이름으로 접속이 안 될 때 씁니다.

## 1단계 — PowerShell 열기

**시작 버튼을 누르고 `powershell` 이라고 친 다음 엔터.**

파란색 창이 뜹니다. 이게 우리가 쓸 창입니다.

> `Windows Terminal` 이 깔려 있으면 그걸 쓰는 게 더 좋습니다. 글자가 더 예쁘게 나옵니다.

**준비가 됐는지 확인해 봅시다.** 아래를 복사해서 붙여넣고 엔터.

```powershell
ssh -V
```

이런 글자가 나오면 준비 끝입니다. **2단계로 가세요.**

```
OpenSSH_for_Windows_9.5p1, LibreSSL 3.8.2
```

<details>
<summary>아무것도 안 나오거나 "인식할 수 없습니다"라고 나오면 (눌러서 펼치기)</summary>

SSH가 없는 겁니다. 설치해야 합니다.

1. PowerShell 창을 닫습니다.
2. 시작 버튼 → `powershell` 을 치고, **마우스 오른쪽 버튼 → 관리자 권한으로 실행**
3. 아래를 붙여넣고 엔터

```powershell
Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0
```

4. 끝나면 `ssh -V` 를 다시 해봅니다.

**관리자 권한이 없어서 안 되면 선생님을 부르세요.**

</details>

## 2단계 — 로봇에 접속하기

먼저 확인하세요.

- [ ] 로봇 전원이 켜져 있나요?
- [ ] 노트북이 로봇과 **같은 와이파이**에 연결되어 있나요?

**`ropi01` 자리에 내 로봇 이름을 넣고** 붙여넣습니다.

```powershell
ssh stone0191@ropi01.local
```

> 붙여넣기는 **마우스 오른쪽 버튼**을 누르면 됩니다.

**처음 접속할 때만** 이런 질문이 나옵니다.

```
Are you sure you want to continue connecting (yes/no/[fingerprint])?
```

`yes` 라고 치고 엔터. (`y` 하나만 치면 안 됩니다. **세 글자를 다 쳐야** 합니다.)

그다음 로봇 비밀번호를 칩니다.

> **비밀번호를 쳐도 화면에 아무것도 안 보입니다.** 고장이 아닙니다. 원래 그렇습니다.
> 그냥 치고 엔터를 누르세요.

이렇게 바뀌면 성공입니다. **이제 여러분의 키보드가 로봇에 연결되었습니다.**

```
stone0191@ropi01:~$
```

### 이름으로 안 되면 숫자 주소를 쓰세요

```
ssh: Could not resolve hostname ropi01.local
```

이렇게 나오면 이름 대신 **적어둔 숫자 주소**를 씁니다.

```powershell
ssh stone0191@192.168.0.64
```

> 윈도우는 `.local` 이름을 못 찾을 때가 종종 있습니다. **숫자 주소는 항상 됩니다.**

## 3단계 — 조종기 실행

접속된 상태에서 아래를 **한 줄씩** 칩니다.

```bash
cd ~/ropi_robot
```

```bash
source venv/bin/activate
```

```bash
python3 raspberry_pi/ropi_teleop.py
```

> **가운데 줄을 빼먹으면 안 됩니다.** `source venv/bin/activate` 를 안 하면
> 화면은 멀쩡한데 로봇만 안 움직입니다.

조종 키 목록이 나오면 준비 끝입니다. **이제 키보드를 누르면 로봇이 움직입니다.**

### 외우기 귀찮으면 한 줄로

2단계와 3단계를 한 번에 하는 방법입니다.

```powershell
ssh -t stone0191@ropi01.local "cd ~/ropi_robot && source venv/bin/activate && python3 raspberry_pi/ropi_teleop.py"
```

## 조종 키

### 움직이기

| 키 | 동작 |
|---|---|
| **↑** 또는 **W** | 앞으로 |
| **↓** 또는 **S** | 뒤로 |
| **←** 또는 **A** | 왼쪽으로 돌기 |
| **→** 또는 **D** | 오른쪽으로 돌기 |
| **Q** | 제자리에서 왼쪽으로 빙글 |
| **E** | 제자리에서 오른쪽으로 빙글 |
| **스페이스** | 멈추기 |

**키를 누르고 있는 동안만 움직입니다.** 손을 떼면 멈춥니다. 로봇이 혼자 굴러가지 않게 하려고 그렇게 만들었습니다.

### 빠르기

| 키 | 동작 |
|---|---|
| **+** | 빠르게 |
| **−** | 느리게 |

### 공격

| 키 | 동작 |
|---|---|
| **F** | 양팔 공격 |
| **J** | 왼팔 |
| **K** | 오른팔 |
| **G** | 콤보 (왼팔 → 오른팔 → 양팔) |

### 인사

| 키 | 동작 |
|---|---|
| **H** | 양손 흔들기 |
| **U** | 왼손 |
| **I** | 오른손 |

### 끝내기

| 키 | 동작 |
|---|---|
| **X** | 조종 끝내기 |
| **?** | 키 목록 다시 보기 |

조종을 끝냈으면 로봇 접속도 끊습니다.

```bash
exit
```

## 내 로봇에 맞게 고치기

로봇마다 모터가 조금씩 달라서, 처음에는 이상하게 움직일 수 있습니다. **고장이 아닙니다.**

### 방향이 이상할 때

**W를 눌렀는데 이렇게 되면:**

| 이런 증상 | 누를 키 |
|---|---|
| 제자리에서 **왼쪽으로** 빙글 돈다 | **1** |
| 제자리에서 **오른쪽으로** 빙글 돈다 | **2** |
| **뒤로** 간다 | **R** |
| 앞으로 잘 간다 | 고칠 필요 없음 |

**F를 눌렀는데 팔이 뒤로 가면** → **T**
**H를 눌렀는데 손이 이상하게 움직이면** → **Y**

### 똑바로 안 갈 때

앞으로 가는데 한쪽으로 휘어지면, **느린 쪽 바퀴를 빠르게** 해줍니다.

| 키 | 동작 |
|---|---|
| **.** | 왼쪽 바퀴 빠르게 |
| **,** | 왼쪽 바퀴 느리게 |
| **'** | 오른쪽 바퀴 빠르게 |
| **;** | 오른쪽 바퀴 느리게 |

### 다 고쳤으면 저장

```
P
```

**P를 눌러야 저장됩니다.** 저장하지 않으면 로봇을 껐다 켰을 때 처음으로 돌아갑니다.

## 안 될 때

### "이런 이름을 못 찾겠다"고 나와요

```
ssh: Could not resolve hostname ropi01.local
```

두 가지를 확인하세요.

1. **노트북 와이파이가 로봇과 같은 것인지** — 다르면 절대 안 됩니다.
2. 그래도 안 되면 **숫자 주소**를 쓰세요. (`ssh stone0191@192.168.0.64`)

### "연결을 거부당했어요"

```
Connection refused
```

**로봇이 아직 켜지는 중입니다.** 1분 기다렸다가 다시 해보세요.

### "시간이 초과됐어요"

```
Connection timed out
```

**로봇 전원이 꺼져 있거나, 와이파이가 다릅니다.** 로봇의 빨간 불이 켜져 있는지 보세요.

### 비밀번호가 안 쳐져요

**원래 화면에 안 보입니다.** 고장이 아닙니다. 그냥 치고 엔터를 누르세요.

### 로봇이 안 움직여요

```
ModuleNotFoundError: No module named 'adafruit_servokit'
```

**`source venv/bin/activate` 를 빼먹은 겁니다.** 3단계를 처음부터 다시 하세요.

### 방향키를 눌러도 반응이 없어요

PowerShell 창을 **마우스로 한 번 클릭**해서 창을 선택한 다음 눌러보세요.

### 바퀴 하나가 아예 안 돌아요

**선을 확인하세요.** 로봇을 옮기다 보면 커넥터가 빠지는 일이 자주 있습니다.
빠진 게 없으면 선생님을 부르세요.

### 로봇이 멈추지 않아요

**스페이스**를 누르세요. 그래도 안 되면 **`Ctrl` + `C`**.
그것도 안 되면 **로봇 전원 스위치를 내리세요.**

## 안전 규칙

1. **팔 동작을 시험할 때는 로봇을 손으로 들고 하세요.** 팔이 세게 휘둘러집니다.
2. **책상 끝에서 주행 시험을 하지 마세요.** 떨어집니다.
3. **모터가 "웅—" 소리를 내면서 안 움직이면 바로 스페이스를 누르세요.** 그대로 두면 모터가 뜨거워집니다.
4. 다 하고 나면 **X** → **`exit`** → **로봇 전원 스위치 내리기**

## 선생님께

**설치가 필요 없다는 게 이 방법의 핵심입니다.** 윈도우 10 (1803 이상)·11에는 OpenSSH 클라이언트가
기본으로 들어 있어서, 학교 노트북처럼 관리자 권한이 막힌 환경에서도 그대로 씁니다.

**대신 이걸 미리 준비해 두세요.**

- **로봇마다 IP 주소를 적어서 나눠주기.** 윈도우의 `.local` 이름 찾기는 환경에 따라 실패합니다.
  IP는 항상 되므로, 이름이 안 될 때를 대비해 반드시 같이 주세요.
- 로봇마다 호스트이름을 다르게 (`ropi01` ~ `ropi10`). 같은 이름이 둘이면 엉뚱한 로봇에 접속됩니다.
- 와이파이 이름·비밀번호를 크게 적어 칠판에 붙여두기
- 수업 전에 8개 커넥터가 다 꽂혔는지 확인 (`ropi_scan.py`)

**말로 조종하려면** → [MANUAL_VOICE_POWERSHELL.md](MANUAL_VOICE_POWERSHELL.md)
음성 AI 도 PowerShell 로 합니다. **WSL 은 마이크에 접근할 수 없어서 쓰면 안 됩니다.**

**학생들이 코드를 직접 고쳐서 로봇에 보내게 할 거라면** (`git`, `scp`)
[MANUAL_WINDOWS.md](MANUAL_WINDOWS.md) 의 WSL 방식이 편합니다.
